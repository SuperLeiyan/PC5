**Test build: 2.0.3-test2 with its two unknowns fixed.** Includes everything in 2.0.3-test and 2.0.3-test2. Publish as a pre-release.

### Install

Copy the `PPSA11018` folder from `PPSA11018.zip` over your PC5 folder. Games, saves and settings stay.

**Going back:** games installed with 2.0.3-test2 or this build need one of them (or newer). On 2.0.2 or 2.0.3-test, install them again. Older games are fine either way.

### Fixed since 2.0.3-test2

- **A game that lists Windows' system folder** now sees Wine's DLLs there, as before 2.0.3-test2.
- **A game that replaces or changes one of Windows' DLLs** gets its own copy of it first, so it can, and the DLL every other game uses stays as it is.
- **Checking for a newer PC5** while the check that starts with PC5 was still running could mix up their answers.

### Please test

Install a game with this build and play it. If it stops at start and works on 2.0.3-test, report it as an [issue](https://github.com/bornaradusin/PC5/issues/new/choose) with its zip from `/data/prospero-win/logs/`.
