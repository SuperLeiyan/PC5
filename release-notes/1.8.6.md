A game started by its own launcher now runs as 32-bit or 64-bit, and with the graphics, that the game's own program needs.

### Install

From PC5 1.8.5, or 1.8.2 that **opens**: **Settings › System › Update now**, or **Update now** when PC5 asks as it opens. From 1.8.0 or 1.8.1: **Settings › Updates › Update now**. PC5 restarts by itself when the update is installed.

From PC5 1.8.2 that **closes at once** with error CE-108255-1 (1.8.3 and 1.8.4, now withdrawn, did the same), either:

- update by hand (below), or
- open `/data/prospero-win/pc5/settings.txt` on the console (FTP, for example), change the `startup_sound = …` line to `startup_sound = off` (add the line if it isn't there), open PC5 and update from it. Choose a sound again afterwards in **Settings › System › Startup sound** if you want one.

By hand:

1. Download `PPSA11018.zip` and unzip it.
2. Replace the `PPSA11018` folder on the console with the new one, the way you add homebrew. Your games, saves and settings stay where they are.
3. Start PC5. Options › About PC5 shows 1.8.6.

Updating from PC5 1.7.0: it closes at the end of the update instead of restarting, and the console then shows error CE-108255-1. The update is installed all the same: open PC5 again.

### What's new

- **A launcher's game starts as itself**: when a game's own launcher starts the game, PC5 closes the launcher and starts the game in its place. It started the game as 32-bit or 64-bit, and with the graphics, noted for the program installed, which is often the launcher. A 32-bit launcher for a 64-bit game, or a launcher that draws differently from its game, started the game wrong. PC5 now reads both from the program the launcher starts, as it does when installing.
- Everything in 1.8.5 is unchanged: PC5 opening with a startup sound chosen, the startup sound's own volume (**Settings › System › Startup sound volume**), the smoother library, a game's own pointer reaching the far side of the screen, older 32-bit games that crashed in kernelbase.dll at startup, CPU sharing, and the console's firmware in logs and reports.

### Which games run

See the [game compatibility list](https://github.com/bornaradusin/PC5/wiki/Game-compatibility), made from players' reports. Got a game running? [Add it](https://github.com/bornaradusin/PC5/discussions/new?category=game-compatibility): the form takes a minute.

### Reporting a problem

Please report problems as an [issue on GitHub](https://github.com/bornaradusin/PC5/issues), not in ProsperoStore's comments, and attach the game's zip from `/data/prospero-win/logs/` (`issue-…zip`, or the game's newest `log-…zip` when nothing crashed). △ on PC5's crash message opens the form for you. Say which PC5 version you use (Options › About PC5) and what happened. Without the log the cause can't be found. If an update from PC5 fails, the message says why; turn on **Settings › System › Keep all logs**, try again and attach PC5's own log. See [Logs and debugging](https://github.com/bornaradusin/PC5/wiki/Logs-and-debugging) for what an issue may ask for.

### Not supported

Games that need a store's launcher or client running (Steam, EA app, Ubisoft Connect, Rockstar Games Launcher), anti-cheat, and games that need kernel drivers. .NET programs that mix .NET and C++ (C++/CLI). 16-bit Windows and DOS programs. Recording or saving video from inside a game. Frame generation for DirectDraw games, games drawn without 3D, and HDR output. Changing a game's controller mode, resolution or aspect ratio while it runs. DRM protected. PC5 installed as a package (`.pkg`) can't update itself: it updates from a folder only.
