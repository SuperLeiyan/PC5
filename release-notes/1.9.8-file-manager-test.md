**A test build: a file manager inside PC5.**

### Install

Download `PPSA11018.zip` below and copy its `PPSA11018` folder over the one you installed PC5 from, as when you added PC5. Your games, saves and settings stay. To go back, install 1.9.8 the same way.

### What to try

1. **A game's own folder:** in the library press **△** on a game PC5 installed, then **Manage › Game files**. It shows only that game's folder.
2. **The whole console:** **Settings › File manager** (between Overlay and System). It starts with Console storage (`/data`), each USB and Extended storage drive, PC5's app and Whole console (those two read-only).
3. **The buttons:** **✕** opens a folder, **□** ticks items, **△** shows what can be done, **○** goes back, **L1 / R1** jump eight rows.
4. **What △ offers:** Copy, Cut, Paste, Rename, New folder, Delete and Tick all. Paste shows a bar and **○** stops it. When the folder has a name already, it asks: Skip, Keep both ("name (2)") or Replace. Delete asks first, with how many files and folders and how much.
5. **Between the two:** copy a mod from a USB drive in Settings › File manager, then paste it in a game's folder from Manage › Game files.
6. **Report on GitHub:** when a newer PC5 is out, **△** on a crash message first offers it, with **Update now** and **Report anyway**.

### What isn't known yet

- How fast copies to and from USB drives are on the console.
- Whether every drive the console mounts shows up in the places.

Please report what you find, with the log zip from `/data/prospero-win/logs/`: its `PC5 files …` lines show what the file manager did.
