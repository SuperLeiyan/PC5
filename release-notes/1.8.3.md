A smoother library; older 32-bit games that crashed in kernelbase.dll at startup carry on; games that look for Windows' 16-bit support no longer close at once; CPU sharing for a game that stops for seconds at a time; and the console's own firmware in logs and reports.

### Install

From PC5 1.8.2: **Settings › System › Update now**, or **Update now** when PC5 asks as it opens. From 1.8.0 or 1.8.1: **Settings › Updates › Update now**. PC5 restarts by itself when the update is installed.

By hand:

1. Download `PPSA11018.zip` and unzip it.
2. Replace the `PPSA11018` folder on the console with the new one, the way you add homebrew. Your games, saves and settings stay where they are.
3. Start PC5. Options › About PC5 shows 1.8.3.

Updating from PC5 1.7.0: it closes at the end of the update instead of restarting, and the console then shows error CE-108255-1. The update is installed all the same: open PC5 again.

### What's new

- **A smoother library**: moving through the covers takes about half the work it did in 1.8.2. The backdrop and the covers are drawn on four threads, a game's background is made ready on a thread of its own and shown once it is, and covers load one a frame while you move.
- **Older 32-bit games that crashed in kernelbase.dll at startup**: a 32-bit game that loads the CPU's FS register itself (which holds where its thread's data is) got the wrong address and crashed at its next use of it, with a page fault at an address like FF81C098. The right address is now put back and the game carries on. PC5's log notes the first time it happens, for a report.
- **Games that look for Windows' 16-bit support**: the console can't run 16-bit code, and a game that looked up one of its functions closed before showing anything. The lookup now fails as on 64-bit Windows, and the game carries on.
- **CPU sharing**: **△ › Graphics › CPU sharing** gives a game's threads turns on the CPUs, as on a PC. The console runs each of them on a CPU of its own until it waits, so a game that keeps more threads busy than its 13 CPUs can stop for seconds at a time, and carry on after a while or after the PS button. Turn it on for such a game. Off by default. See [Graphics](https://github.com/bornaradusin/PC5/wiki/Playing-games#graphics).
- **The console's firmware in logs and reports**: PC5 reads it from the console's own system, so a report names the firmware Settings › System › System Software shows. The number homebrew tools can change is noted beside it when the two differ.
- Everything in 1.8.2 is unchanged: the library's new look with the covers on a mirrored floor, Settings › System, picture sources that can each be turned off, Java games, games started from a batch file, and the startup sound at the console's volume.

### Which games run

See the [game compatibility list](https://github.com/bornaradusin/PC5/wiki/Game-compatibility), made from players' reports. Got a game running? [Add it](https://github.com/bornaradusin/PC5/discussions/new?category=game-compatibility): the form takes a minute.

### Reporting a problem

Please report problems as an [issue on GitHub](https://github.com/bornaradusin/PC5/issues), not in ProsperoStore's comments, and attach the game's zip from `/data/prospero-win/logs/` (`issue-…zip`, or the game's newest `log-…zip` when nothing crashed). △ on PC5's crash message opens the form for you. Say which PC5 version you use (Options › About PC5) and what happened. Without the log the cause can't be found. If an update from PC5 fails, the message says why; turn on **Settings › System › Keep all logs**, try again and attach PC5's own log.

### Not supported

Games that need a store's launcher or client running (Steam, EA app, Ubisoft Connect, Rockstar Games Launcher), anti-cheat, and games that need kernel drivers. .NET programs that mix .NET and C++ (C++/CLI). 16-bit Windows and DOS programs. Recording or saving video from inside a game. Frame generation for DirectDraw games, games drawn without 3D, and HDR output. Changing a game's controller mode, resolution or aspect ratio while it runs. DRM protected. PC5 installed as a package (`.pkg`) can't update itself: it updates from a folder only.
