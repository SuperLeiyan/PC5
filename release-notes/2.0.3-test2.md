**Test build: smaller PC5, smaller games, no wait at start.** Includes everything in 2.0.3-test. Publish as a pre-release.

### Install

Copy the `PPSA11018` folder from `PPSA11018.zip` over your PC5 folder. Games, saves and settings stay.

**Going back:** games installed with this build need it (or newer). On 2.0.2 or 2.0.3-test, install them again. Older games are fine either way.

### What's new

- **Games take about 300 MB less each** and install faster: Wine's DLLs are no longer copied into every game.
- **PC5 is about 110 MB smaller to download.**
- **The library shows at once**: the update check runs in the background.

### Please test

Install a game with this build and play it. If it stops at start and works on 2.0.3-test, report it as an [issue](https://github.com/bornaradusin/PC5/issues/new/choose) with its zip from `/data/prospero-win/logs/`.
