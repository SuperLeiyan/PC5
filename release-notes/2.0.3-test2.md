**A second test build of PC5 2.0.3: a smaller PC5, smaller games, and no wait at start.** It has everything 2.0.3-test has. Publish it as a pre-release: PC5's own updater and ProsperoStore don't offer it.

### Install

Download `PPSA11018.zip` below and copy its `PPSA11018` folder over the one you installed PC5 from, as when you added PC5. Your games, saves and settings stay.

**Going back:** a game you install with this build works only with it or a newer PC5. On 2.0.2 or 2.0.3-test it is missing Windows' own files: install it again there. Games installed before keep working on any version.

### What's new

- **Each game you install takes about 300 MB less.** A game's Windows had its own copy of Wine's DLLs. Wine now finds them in PC5's own folder instead, so installing copies about 60 MB instead of 360 MB and finishes sooner. PC5 also needs less free space to start installing.
- **PC5 is about 110 MB smaller to download** and 300 MB smaller on the console: it held those DLLs twice. Wine Mono's C# and Visual Basic compilers are left out as well (11 MB): no game builds itself.
- **The library shows at once.** PC5 asked GitHub for a newer version before showing your games, which could take seconds on a slow network or with the console offline. It now asks in the background, and offers a newer PC5 over the library once it knows.

### What isn't known yet

- Whether every game finds the Windows files it looks for. A game that asks Windows to list its system folder doesn't see Wine's DLLs in that list. That should be rare; if a game you install with this build stops at start, try installing it with 2.0.3-test and compare.
- Whether a game that replaces one of Windows' DLLs with its own still can.

Please report what works and what doesn't as an [issue](https://github.com/bornaradusin/PC5/issues/new/choose), with the game's zip from `/data/prospero-win/logs/`.
